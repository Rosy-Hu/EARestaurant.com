# EA中餐馆｜2026年9月 Newsletter 手机版

本版根据用户提供的大众点评手机端截图重新设计，重点还原真实点评详情页的信息层级和移动端浏览体验。

## 页面结构

- 顶部搜索栏与图片轮播
- 餐厅评分、榜单、营业时间、标签和地址
- 优惠券与本月赢单套餐
- 重点项目活动
- 推荐菜与网友推荐菜
- 商家新鲜事
- 生日宴
- 食客评价
- 底部收藏、写评价、立即打卡操作栏
## 本地打开

直接双击 `index.html`。桌面浏览器中会自动限制为手机宽度并居中显示；手机浏览器中会自动铺满屏幕。

## 内容替换

所有文本与图片路径集中在 `data/content.js`：

- `restaurant`：餐厅名称、评分、标签、人均数据
- `menu`：赢单项目与推荐菜
- `signature`：重点项目
- `reviews`：同事评价
- `event`：分享会
- `birthdays`：生日宴

## 图片替换

覆盖 `assets/` 中对应图片即可，或在 `data/content.js` 中修改路径。

## 发布前检查

1. 替换所有示例项目、姓名、日期和评价内容。
2. 确认头像、照片和同事信息已获得授权。
3. 将图片压缩为 WebP，降低手机加载时间。
4. 在手机浏览器中检查实际显示效果。
5. 部署整个目录到公司内网服务器或静态托管平台。
